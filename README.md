# Protutech

Personal tactical utility and strategy platform for Counter-Strike 2.

## Development

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build production bundle:
```bash
npm run build
```

## Server Run

```bash
npm run server
```

## Docker Deployment

```bash
docker compose up -d --build
```
